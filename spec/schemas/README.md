# Schemas

Published machine schemas used by `a2h` to validate Agent System source and compatibility reports.

- Source: `source/v1alpha1/` (Agent Spec; v1alpha1 AgentSystem)
- Source System v1alpha2: `source/v1alpha2/` (required `work_root`)
- Artifact: `artifact/agent2host-system-v1.schema.json`
- Compatibility report: `compatibility/v1alpha1/`

Instance strings use the `agent2host/...` namespace. `$id` values are URNs (`urn:agent2host:schema:…`).
